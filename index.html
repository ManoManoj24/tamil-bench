Methodology முறையியல்

The exams

  • MILU — 199 Tamil MCQs from Indian competitive exams (AI4Bharat + IBM Research, CC-BY-4.0). Metric: accuracy.
  • IndicQA — 100 reading-comprehension questions over Tamil Wikipedia passages (AI4Bharat, CC-BY-SA-4.0). Metrics: exact match + F1.
  • IndicXNLI — 200 three-way logic questions: entail, contradict, or neutral (repaired mirror of AI4Bharat's IndicXNLI). Metric: accuracy.
  • Bluff catch — unanswerable IndicQA traps: does the model abstain or invent an answer? Lower bluff rate wins.

The rules

  • Zero-shot for MILU/XNLI; 5-shot for MILU only where noted. Temperature 0.
  • Fixed random seed (42); MILU sampled stratified by subject.
  • API errors and unparseable answers count as wrong — they stay in the denominator.
  • 95% Wilson confidence intervals on every accuracy-style score.
  • API-only models, no GPUs. Every answer sheet is saved in the repo.

The Overall score

Overall is the mean of the three core task scores — MILU accuracy, IndicQA F1, IndicXNLI accuracy — each on a 0–100 scale, rounded to one decimal. A model missing any core task gets no Overall and is listed below the ranked models as partial.

Bluff rate is excluded: lower is better there, so it can't average with accuracy-style metrics. It has its own tab.

What is Tamil Bench? தமிழ்த் திறனாய்வு என்றால் என்ன?

AI chatbots are tested on English constantly, and on a handful of other big languages. Tamil — spoken by ~85 million people — usually gets one line in a table, if it appears at all. Tamil Bench fixes the measuring stick: three exams, entirely in Tamil script, marks published for all to see.

AI மாதிரிகள் தொடர்ந்து ஆங்கிலத்தில் சோதிக்கப்படுகின்றன; சுமார் 8.5 கோடி மக்கள் பேசும் தமிழ் பெரும்பாலும் அட்டவணையில் ஒரு வரியாக மட்டுமே தோன்றுகிறது. Tamil Bench அந்த அளவுகோலைச் சரிசெய்கிறது: முழுவதும் தமிழில் மூன்று தேர்வுகள், மதிப்பெண்கள் அனைவருக்கும் திறந்தவை.

Think of it as a report card. Anyone can re-run the exam on any model through its API — no GPU, a few dollars at most — and every answer sheet is saved in the repo, so no score is taken on trust.

இது ஒரு அறிக்கை அட்டை போன்றது. யாரும் API மூலம் எந்த மாதிரியிலும் தேர்வை மீண்டும் நடத்தலாம்; ஒவ்வொரு விடைத்தாளும் சேமிக்கப்படுவதால் மதிப்பெண்களைச் சரிபார்க்கலாம்.

The headline finding so far: models ace the exam MCQs but stumble on reading comprehension — knowing facts in Tamil and reading Tamil precisely are two different skills.

இதுவரையிலான முக்கிய முடிவு: தேர்வு வினாக்களில் மாதிரிகள் சிறக்கின்றன; வாசிப்புப் புரிதலில் தடுமாறுகின்றன — தமிழில் அறிவதும், தமிழைத் துல்லியமாகப் படிப்பதும் வெவ்வேறு திறன்கள்.

Run it yourself நீங்களே இயக்குங்கள்

One model, all three exams, one command. Bring an OpenRouter API key.

Setup
git clone https://github.com/ManoManoj24/tamil-bench
cd tamil-bench
pip install -r requirements.txt
export OPENROUTER_API_KEY=sk-or-...
Run the bench
python3 bench.py all --model z-ai/glm-5.3-flash --n 100
python3 bench.py --list-models   # what else you can test

MILU needs a free Hugging Face gate accept (HF_TOKEN). Results land in results/ as JSONL — one line per question, fully auditable.
